# Калькулятор Расходов (Food Calc)

Простой и удобный веб-инструмент для расчета расходов в кафе и ресторанах для группы друзей.

## Возможности

*   **Чек по фото:** кнопка «Чек» → фото → позиции, количество, цены, сервис и дата распознаются сами (с QR фискального чека берутся дата и итог). Сумма позиций сверяется с итогом чека. Дальше — разметка «кто что ел» нажатием на имена: всё по умолчанию «на всех», позиции из нескольких штук можно делить между людьми.
    *   С бесплатным ключом **Gemini** ([aistudio.google.com/apikey](https://aistudio.google.com/apikey)) распознавание почти без ошибок. Ключ хранится только на устройстве; фото отправляется в Google.
    *   Без ключа (или если Gemini недоступен) работает бесплатное распознавание прямо в браузере (Tesseract.js); при первом запуске загружается ~5 МБ.
*   **Учет участников:** Добавление имен участников.
*   **Личные заказы:** Добавление блюд для каждого участника.
*   **Общие блюда:** Добавление блюд, которые делятся на всех (например, пицца, закуски).
*   **Автоматический расчет:**
    *   Личные расходы каждого участника.
    *   Распределение стоимости общих блюд поровну.
    *   Учет процента за обслуживание (комиссия).
    *   Итоговая сумма чека.
*   **История чеков:** Сохранение и просмотр прошлых расчетов (используется LocalStorage браузера). Кнопка «Сохранить текущий чек» в окне истории; повторное сохранение обновляет запись, а не создаёт дубликат.
*   **Скриншот чека:** Возможность сделать красивый скриншот итогового расчета для отправки друзьям. На телефоне — кнопка «Поделиться», чтобы сразу отправить картинку в Telegram, WhatsApp и т. п.
*   **Темная/Светлая тема:** Переключение интерфейса.
*   **Управление плательщиком:** Указание того, кто оплатил счет, и расчет долгов остальных участников перед ним.
*   **Копирование реквизитов:** Быстрое копирование номера карты/кошелька плательщика.

## Как использовать

1.  Откройте сайт или файл `index.html` (вместе с `style.css` и `app.js`) в любом современном веб-браузере (Chrome, Firefox, Safari, Edge).
2.  **Добавьте участников:** Нажмите "Блюдо" и введите имя участника и название блюда.
3.  **Добавьте общие блюда:** Нажмите "Общее" для добавления блюд на всех.
4.  **Укажите сервис:** Введите процент обслуживания в поле "Сервис (%)" и нажмите галочку.
5.  **Выберите плательщика:** В поле "Плательщик" выберите того, кто оплатил счет.
6.  **Укажите реквизиты:** (Опционально) Введите номер карты/кошелька для возврата долга.
7.  **Скриншот:** Нажмите кнопку "Скриншот", чтобы получить картинку с расчетом.

## Технологии

*   HTML5
*   CSS3 (Flexbox, Grid, CSS Variables)
*   JavaScript (ES6+)
*   Font Awesome (иконки)
*   html2canvas (для создания скриншотов)
*   Google Fonts (Inter, Montserrat)

## Структура

*   `index.html` — разметка страницы
*   `style.css` — стили
*   `app.js` — логика расчёта и интерфейса
*   `receipt.js` — экран «Чек»: фото, распознавание (Gemini / Tesseract), разметка
*   `receipt-parse.js` — разбор распознанного текста чека в позиции

После изменения `.css` или `.js` файла увеличьте номер его версии в `index.html` (например, `app.js?v=4` → `?v=5`), чтобы у пользователей не осталась старая копия файла из кэша браузера.

## Установка

Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html`. Все три файла должны лежать в одной папке. Интернет нужен только для загрузки шрифтов, иконок и html2canvas (CDN).
